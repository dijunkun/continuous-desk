# **更新内容**

1. 新增原生iOS/iPadOS客户端v0.0.1，支持远程画面与音频、触控鼠标和键盘输入、多显示器切换、双向文件传输及接收远端文本剪贴板。
2. 完善iOS远程操作体验，提供相对位置与绝对位置鼠标模式、捏合缩放及悬浮控制菜单，支持查看连接状态、P2P/中继模式、分辨率与码率；修复切回前台后画面无法恢复、相对鼠标跳动及灵动岛遮挡控件等问题。
3. 新增帧率优先、画质优先和平衡三种画面偏好，优化带宽变化时的分辨率、帧率与码率调节，提升远程桌面的清晰度和流畅度。
4. 优化Windows与macOS原生视频采集、硬件编码和渲染流程，减少画面拷贝；Linux新增CUDA/OpenGL视频渲染，提升硬件解码画面的显示效率。
5. 优化P2P连接建立与UPnP支持，支持连接从中继升级为P2P，并改进ICE连接、视频恢复及音视频时间戳处理，提升弱网和网络变化时的连接稳定性。
6. 修复Windows锁屏界面无法远程控制，以及部分设备因OpenGL初始化失败导致启动崩溃的问题，优化锁屏画面采集与恢复。
7. 修复桌面端与iOS端设备在线状态更新不及时、桌面端启动后托盘图标未显示的问题，并将连接清理移出界面线程，减少断开连接时的卡顿。
8. 完善iOS与桌面端跨平台构建和打包流程，更新界面截图、构建指南、自托管说明及常见问题文档。

PC客户端版本为v1.5.0，iOS/iPadOS客户端使用独立版本号，本次为v0.0.1。iOS/iPadOS客户端要求iOS 16.0及以上版本和arm64真机，提供的构建包为未签名应用，需要自行签名后安装；目前仅支持作为控制端连接电脑。
